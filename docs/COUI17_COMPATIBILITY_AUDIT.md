# COUI17 组件、动效与非 ColorOS 兼容性检查

## APK 参考

通过 APK 的 DEX 类定义、资源表和动画 XML 核对组件覆盖与参数。相册和文件管理是提供的 APK，系统设置和小布助手通过无线 ADB 提取。

| 应用 | 版本 | 参考范围 |
| --- | --- | --- |
| 相册 | 17.24.79 | 2,319 个 `com.coui` 类定义。重点看工具栏、菜单、搜索、滑杆、面板和悬浮控件。 |
| 文件管理 | 17.10.4 | 1,257 个 `com.coui` 类定义。重点看列表操作、偏好行和面板。 |
| 系统设置 | 17.0.0 | 2,660 个 `com.coui` 类定义。补充偏好行、搜索和表单。 |
| 小布助手 | 13.4.3 | 使用 Android 16 SDK。补充核对搜索、工具栏尺寸和窗口动画。 |

三个 17 系列 APK 使用的资源包括悬浮导航 56dp、高度 48dp 的导航项、168dp 的列表弹窗最小宽度、52dp 的搜索栏行，以及 2dp、4dp、6dp 的意图滑杆静止轨道。居中确认对话框的单行按钮为 44dp，多行按钮最小 56dp。系统设置和小布助手的 XML 中，居中对话框进入 250ms、退出 150ms，列表弹窗末段窗口淡出 200ms。相册和系统设置还提供对话框的 200 与底部面板的 400 两个原生模糊半径参数，与组件库中的原生参数定义一致。Compose 渲染路径按引擎的半径单位换算。资源覆盖和 XML 时长只用于对照组件契约，实际动画还包含窗口、手势和遮罩状态。

## 背景如何取样

| 区域 | 背景和时机 |
| --- | --- |
| 大标题栏、搜索栏、双行工具栏 | 采样标题栏下面录入 `LayerBackdrop` 的内容。沿纵向从顶部的强模糊递减至下缘的清晰内容。标题栏本体在录制层外，标题和操作按钮保持清晰。 |
| 悬浮导航、浮动输入 | 采样同窗口内其后方的滚动内容。形状限制模糊的范围，再叠加当前主题的着色。 |
| 独立窗口的菜单、面板和对话框 | `PixelCopy` 采样直接宿主窗口，宽高各缩为四分之一。首次有区域时取样，之后在宿主重绘时更新，两次取样至少相隔 33ms，同时只执行一次复制。 |
| 对话框上再开菜单 | 上层采样对话框窗口，按屏幕坐标与其下方的宿主采样叠合。父窗口的透明区保留下一层画面，菜单开合中的缩放不会缩放背后页面。 |
| 关闭模糊或缺少着色器 | 采用当前浅色或深色主题的实体填充。标题栏的按钮与内容排版保持同一套尺寸。 |

## 修复与验收范围

| 范围 | 调整与验收 |
| --- | --- |
| 标题栏、顶部渐进模糊 | 保留 Gallery 风格的渐进曲线和滚动选项。有背景时才测量额外渐隐带，缺少背景时用标题栏高度内的填充。测试同一滚动位置切换系统模糊，大标题和紧凑标题栏的像素均随设置变化。 |
| 悬浮导航、工具栏、浮动输入 | Compose 材质为默认路径。有背景时绘制玻璃及边缘光，关闭模糊时使用实体填充。测试导航切换、悬浮输入栏的模糊切换及键盘输入。 |
| 菜单、对话框、底部面板 | 菜单在进出场中采样宿主窗口，弹窗与调用处使用同一套密度和字体缩放。测试菜单选择、长按锚点、开启时切换模糊、深浅色确认对话框、选项对话框和底部面板返回。浅色和深色均验证了对话框里的二级菜单，以及退出动画期间约 150ms 后的重开。在 280dpi 和 320dpi 分别量到弹窗行宽 294px 和 336px，均为 168dp。 |
| 按钮、按压动画 | 已开始的拖动回到触摸死区时继续更新位置。手势配置变化时清除按压缩放、光效和位移。逐帧检查录屏，普通按钮在按住时收缩，松开后回弹。另录制了对话框和面板的进出场。 |
| 开关、复选、单选、偏好行 | 合并同一动作的无障碍状态，保留有独立动作的复选行。测试点击开关整行和滑块、复选及单选的状态更新。 |
| 滑杆、数字选择器 | 修复点按、RTL 镜像、缓冲段和禁用语义。数字选择器使用 Android 的系统触感和音效。用模拟器测试 LTR 和 RTL 点按、逐档拖动、数字选择器滚动。 |
| 其他组件 | [组件目录](COMPONENTS.md) 列出源码入口。预测返回、折叠屏布局及各设备上的视觉精度仍需实测。 |

## 组件逐项对照

| 组件 | APK 参考与本次调整 |
| --- | --- |
| 导航轨 | 相册的导航项目宽 64dp，两侧各 4dp，列表顶部和底部分别留 4dp、16dp。图标与文字使用状态选择器对应的主题色，禁用项使用禁用文字色，标签为 medium 字重，最多两行。 |
| 搜索栏 | 相册、文件管理和设置使用 52dp 搜索栏行，包含 40dp 输入胶囊。取消按钮与胶囊相距 10dp，按钮距窗口末端按宽度采用 4、12、28dp。60dp 位移动效按书写方向镜像。 |
| 日历 | 相册的日历标题有 16dp 展开箭头，月份和年份两个页面的 XML 进场 280ms、退场 150ms。补齐标题展开、年份列表和返回，切换到目标月份时将日期限制在有效范围内。年份列表行高暂用 48dp，仍需原机核对。 |
| 日期与数字滚轮 | 核对了相册、设置的 76/62dp 列宽、12dp 竖向留白以及 640dp 宽度上限，库中的相应默认值与资源一致。 |

## Gallery 演示入口

| 页面 | 可操作的场景 |
| --- | --- |
| 组件 · 日期与时间 | 公历日历支持点标题选择年份，与日期滚轮共用同一日期。农历单独选择，时间可切换 12 / 24 小时制，数字滚轮有上下限。 |
| 组件 · 颜色选择 | 在预设色样、色板和 HSV、OKHSV、OKLAB、OKLCH 之间切换，观察当前颜色。 |
| 组件 · 搜索 | 从历史记录或建议提交，观察加载和结果过渡，测试取消、删除记录和空结果。 |
| 组件 · 导航与工具栏 | 固定底栏显隐、悬浮底栏、附加按钮融合作用、导航轨、抽屉和编辑工具栏的横向滚动。 |
| 组件 · 安全输入 | 固定演示码、自带数字键盘的成功与失败状态、图案轨迹以及密码字段。 |
| 组件 · 偏好行变体 | 行内改名、步进器、滑块、独立窗口与页内选项菜单，以及控件与整行各自的点击回调。 |
| 弹层 · 专用对话框 | 进度、加载和安全确认可切换独立窗口或页内；引导可通过翻页和按钮完成。 |

执行 `python -I tools/gen_component_catalog.py --gallery-coverage` 可按组件查看 Gallery 源码中的直接调用位置。复合组件可间接使用其他 API，多个重载也可能共用一个目录项。源码调用仅表明示例使用了该 API，交互与视觉对照仍以实测为准。

默认材质使用 Compose 和 Android 公共图形 API。库仍提供主动启用 ColorOS 原生材质的选项，也会读取系统可访问的模糊偏好。缺少运行时着色器或禁用模糊时，玻璃控件走实体填充。动态验证使用 Android API 37 的 Google 模拟器，硬件触感和同机逐帧像素对照尚未验证。


COUI17 Gallery 和 SwitchTether Debug APK 均通过构建。SwitchTether 联调通过 Gradle 临时指向独立 COUI17 工作树，产出的 APK 在同一原生 Android 模拟器上启动到配对引导页。16 项库内 JVM 测试通过，0016 至 0019 和原有上游补丁可完整重放。

## 点按与拖选

普通、分档、范围和竖向滑块接受点击。连续滑块用绘制滑块的轨道计算落点，分档滑块吸附到对应档位。浮动导航和单选列表可长按后拖动到另一项，松手提交。早于长按阈值开始的单选列表滑动继续用于滚动列表。

悬浮输入框参考小布输入区的连续圆角。底色和背板采样沿用 COUI17 悬浮工具栏在亮色、暗色下的材质配置。输入对话框和输入组件演示页使用同款填充和圆角。Gallery 的三点菜单演示二级排序，返回键先收起二级，点击二级选项后收起整个弹层。


## 2026-11-28 实机对照（ColorOS 17.0.1，PKJ110，1440×3168 @640dpi）

通过无线 ADB 录屏（120Hz）逐帧测量文件管理 17.10.4、时钟 17.6.106 和系统设置 17.0.0，再与反编译的文件管理、壁纸与个性化 17.0.21 交叉核对。结果写进补丁 0026、0027。

| 项目 | 实机测量 | 处理 |
| --- | --- | --- |
| 底部面板入场 | 时钟新建闹钟（全屏面板）：临界阻尼弹簧，ζ=1.00、ω=14 rad/s，response 0.45s，拟合残差 2.2px。COUI17 半屏面板为 ζ=0.96、ω=18.25（response 0.34s），与 `0.25→0.45` 随面板高度插值一致 | 保持 |
| 面板工具栏 | 胶囊按钮中心距面板顶边 36dp，按钮 60×40dp，标题字重约 550 | 工具栏 52dp，标题 550、最多两行 |
| 确认框 | 文件管理、时钟、账号中心、系统更新的确认框都贴底，左右 16dp；入场弹簧 ω≈25、ζ≈0.92，退场约 100ms 加速滑出；删除键为红字 | `AlertDialogStyle.Bottom`、`ConfirmDialog(destructive)` |
| 对话框按钮 | 按钮约 246，比面板（约 229）亮。COUI17 原先按钮比面板暗：按钮配色在宿主组合里取默认值，宿主没有 backdrop，于是一直走不透明回退色 | 在对话框窗口内解析按钮配色 |
| 输入对话框 | 下划线输入框，带字数和清除按钮；打开即弹键盘并全选文字，对话框随键盘升起 | `FormDialog` 自动切换下划线样式并聚焦 |
| 弹出菜单 | 锚点间距 48px=12dp，宽 168dp，行高 40dp；从锚点角放大，约 190ms 到位，无明显回弹；选中项为黑色文字和黑勾；排序菜单的当前项在行尾显示方向箭头 | 12dp、中性选中色、`LocalDropdownCheckIcon` |
| 大标题 | 设置页标题随列表滚动连续上移、缩小、淡出 | `COUIScrollBehavior` 改为跟手 |
| 列表惯性 | 设置首页约 7,000px/s 的 fling：每帧位移呈指数衰减，摩擦系数 2.4–2.7/s，滑行两秒以上 | `pageFlingBehavior()` |

未能实测：设置页搜索展开（该窗口不出现在录屏中）；8:36 之后所有独立窗口（弹窗、对话框）都从录屏中消失，原因未查明，之后的对话框和菜单只用截图核对外观。深色模式、折叠屏和平板布局本次没有对照。
